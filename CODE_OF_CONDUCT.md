# Code of conduct

PHP Station follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be kind and respectful.
- Assume good intent.
- Keep the discussion about the code.
- Harassment, insults and personal attacks are not accepted.

To report unacceptable behaviour to the maintainers, contact them via [x8code.com](https://x8code.com). Every report is reviewed and handled in confidence.
